# torch-learn

`torch-learn` 用于沉淀 PyTorch、torch_npu 和 Inductor 相关的学习笔记、需求设计、
问题定位日志、复现脚本、公共工具和可复用分析流程。

## 仓库内容

- `docs/`: 面向阅读和检索的文档内容，包括学习笔记、需求设计和问题定位日志。
- `scripts/`: 测试、复现、分析和工具脚本及其说明。
- `artifacts/`: 问题定位和源码分析中需要长期引用的生成产物。
- `skills/`: Torch 相关技能说明和可复用分析流程。
- `templates/`: 学习笔记、问题定位日志、需求设计和 skill 的写作模板。

## 常用入口

- 文档首页：`docs/index.md`
- 学习笔记：`docs/notes/`
- 需求设计：`docs/requirements-design/`
- 问题定位日志：`docs/issue-logs/`
- 脚本索引：`scripts/README.md`
- 分析产物：`artifacts/README.md`
- Skills：`skills/README.md`
