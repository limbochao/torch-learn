   55:     """Extract and normalize the call method body from generated wrapper code.
   56: 
   57:     Strips noise (comments, assert_size_stride, del statements, args.clear())

   59:     stream declarations, context switches, event ops, kernel calls, buffer allocations.

   63:     # Find the call function body

   67:         if "def call(" in line:

   69:             call_start = i + 1
